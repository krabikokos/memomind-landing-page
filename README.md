# 🚀 MemoMind Landing Page

## Project Overview
This project is a modern, single-page website (Landing Page) developed as a portfolio piece to showcase key Front-end development skills. It is built to be a professional, fully responsive website for a fictional note-taking service called **MemoMind**.

## ✨ Key Features
* **Fully Responsive Design:** Optimized for seamless viewing on all devices (mobile, tablet, and desktop) using CSS Media Queries.
* **Light/Dark Theme Toggle:** Users can switch between a light and dark color scheme using a stylish button, with the preference saved in the browser's Local Storage (Vanilla JavaScript).
* **Custom Color Palette:** Uses a clean, modern color scheme (Primary: `#52b69a` / Secondary: `#90e0ef`).
* **Interactive Elements:** Includes an animated **Hamburger Menu** for mobile navigation and interactive social media icons (Font Awesome).
* **Client-Side Form Validation:** The Contact Form includes basic validation implemented with **Vanilla JavaScript** to ensure required fields are filled before submission.

## 🛠️ Tech Stack
* **HTML5** (Semantic structure)
* **CSS3** (Custom Properties / Variables for themes, Flexbox, Grid)
* **JavaScript** (Vanilla JS - no frameworks)
* **Font Awesome** (For professional icons)

## 📌 Setup and Installation
To run this project locally, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https:https://github.com/krabikokos/memomind-landing-page
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd memomind-landing-page
    ```
3.  **Open the file:** Simply open the `index.html` file in your preferred web browser.
